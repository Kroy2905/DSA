🗺 Android Interview Roadmap

Targeting Google, Meta, FAANG-level Android roles. 4–6 month structured plan from fundamentals to system design.

What Google Tests

40% — DSA

LeetCode medium-hard. 2 coding rounds. Trees, Graphs, DP, Sliding Window, BFS/DFS. Purely CS — no Android in these.

30% — System Design

Design a mobile app at scale. Offline-first, caching, pagination, architecture decisions. 1 dedicated round.

30% — Android Depth

Lifecycle, threading, Jetpack, Compose, architecture, Kotlin, performance. Expect "why" not just "what".

Month-by-Month Plan

M1Android Core + Kotlin FundamentalsStart here

Week 1-2 — Android Fundamentals:

  • Activity & Fragment lifecycle — draw it from memory
  • Intent types (explicit/implicit), PendingIntent
  • Task, Back Stack, Launch Modes (standard, singleTop, singleTask, singleInstance)
  • Context types — Activity, Application, Service context; when to use each
  • BroadcastReceiver (static vs dynamic), Service (started, bound, foreground)
  • ContentProvider, ANR causes, Memory leak patterns

Week 3-4 — Kotlin Mastery:

  • Scope functions: let, apply, run, also, with — know exactly when to use each
  • Sealed classes, data classes, object declarations
  • Extension functions, Higher-order functions, Lambdas
  • Null safety — ?., !!, let/run for null checks
  • Generics, variance (in/out covariance), reified type parameters
  • Delegation — by lazy, by observable, interface delegation
  • inline, noinline, crossinline — understand bytecode implications

Daily DSA (30 min): Arrays, Strings, HashMaps. LeetCode Easy. Target 1-2 problems/day.

M2Architecture + Coroutines + FlowIntermediate

Architecture:

  • MVVM, MVP, MVI — differences, tradeoffs, when to choose each
  • Clean Architecture — Domain / Data / Presentation layers
  • Repository pattern — single source of truth
  • UseCase (Interactor) layer — pure business logic, easy to test
  • ViewModel — why it survives rotation (ViewModelStore, retain fragment)
  • LiveData vs StateFlow vs SharedFlow — lifecycle awareness, hot vs cold
  • UiState pattern — sealed class for loading/success/error

Coroutines & Flow:

  • suspend functions, coroutine builders: launch, async, runBlocking
  • Dispatchers — Main (UI), IO (network/disk), Default (CPU), Unconfined
  • Structured concurrency — scope, Job, SupervisorJob, cancellation
  • Flow (cold) vs StateFlow/SharedFlow (hot)
  • Flow operators: map, filter, flatMapLatest, combine, zip, debounce
  • Exception handling — try/catch in suspend, CoroutineExceptionHandler

DSA: Trees, Linked Lists, Two Pointers. LeetCode Easy-Medium.

M3Jetpack Compose + DI + Networking/StorageIntermediate

Jetpack Compose:

  • Composable functions, recomposition, smart recomposition
  • State: remember, rememberSaveable, State hoisting pattern
  • Side effects: LaunchedEffect, SideEffect, DisposableEffect, derivedStateOf
  • Navigation: NavHost, NavController, type-safe args, deep links
  • Custom layouts, Modifiers (order matters!), Canvas drawing

DI — Hilt (Google's recommended):

  • @HiltAndroidApp, @AndroidEntryPoint, @HiltViewModel
  • @Inject, @Provides, @Binds, @Module, @InstallIn
  • Scopes: SingletonComponent, ViewModelComponent, ActivityComponent
  • Dagger 2 fundamentals (Hilt is built on it)

Networking & Storage:

  • Retrofit + OkHttp interceptors (logging, auth token)
  • Room: Entity, DAO, Database, TypeConverters, migrations
  • DataStore (Preferences + Proto) vs SharedPreferences
  • Offline-first architecture with single source of truth

DSA: Graphs, BFS/DFS, Binary Search, Stack/Queue. LeetCode Medium.

M4Advanced Android + Testing + PerformanceAdvanced
  • Custom Views: measure/layout/draw cycle, onMeasure/onLayout/onDraw
  • RecyclerView internals: RecycledViewPool, DiffUtil, ItemAnimator, ConcatAdapter
  • Paging 3: PagingSource, RemoteMediator, PagingData
  • WorkManager: Worker, CoroutineWorker, constraints, chaining
  • Performance: Systrace, Profiler, Jank/janky frames, overdraw, hierarchy viewer
  • Memory: LeakCanary, weak/soft references, bitmap recycling
  • Animations: Property animator, ObjectAnimator, Transition API, Compose animations
  • Testing: JUnit5, MockK, Turbine (Flow testing), Espresso, Compose UI tests

DSA: Dynamic Programming, Backtracking, Heap/Priority Queue. LeetCode Medium-Hard.

M5–6System Design + Mock Interviews + BehavioralGoogle Level

Mobile System Design (practice these):

  • Design Instagram Feed (infinite scroll, caching, offline)
  • Design WhatsApp (messaging, delivery receipts, encryption)
  • Design Uber (real-time location, maps, surge pricing)
  • Design an Image Loading Library (like Glide/Coil)
  • Design a Video Streaming app (YouTube)
  • Design Twitter (Timeline, trending, notifications)

Framework for any mobile design question:

  1. Clarify requirements (functional + non-functional)
  2. High-level architecture (layers, components)
  3. Data models (what data do we store)
  4. API design (what does the app call)
  5. Key screens and navigation
  6. Networking strategy (pagination, caching, offline)
  7. Performance and optimization

DSA: LeetCode Hard problems. Practice timed coding (45 min per problem).

Behavioral (STAR format): Prepare 5-6 stories about impact, conflict resolution, technical leadership, failure and learning.
